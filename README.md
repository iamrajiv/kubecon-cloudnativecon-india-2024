# WebAssembly Profiling with pprof and wzprof

KubeCon + CloudNativeCon India 2024, 11th–12th December 2024

- Rajiv Ranjan Singh
- Naman Lakhwani

## About

What profiling actually measures and how pprof collects it in Go, then the same
investigation for a WebAssembly program with wzprof: generating CPU and memory
profiles, and reading the results back.
